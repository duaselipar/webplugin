# 1. Destroy Timer
*Requires a USER object.*
*Example:* `sys_clearTime 123456`

* **Parameter 1:** Timer ID to be closed/destroyed.
* **Return Value:** Always returns success.
* **Note:** Use this when a periodic execution is no longer needed.

---

# 2. Execution Track (Sync Track)
*Requires a USER object. Used for combo skills (e.g., Flying Combo) to control character movement and actions via script.*
*Example:* `sys_syncTrackTo 10003952 100 100 0 1000030`

* **Parameter 1:** Target User ID (`user_id`).
* **Parameter 2:** X coordinate (Target displacement/offset).
* **Parameter 3:** Y coordinate (Target displacement/offset).
* **Parameter 4:** Direction (0–7 for 8-way facing).
* **Parameter 5:** Track ID (Must be configured in the client).
* **Return Value:** Always succeeds.

---

# 3. Check Timer
*Requires a USER object (Version 008 and above).*
*Example:* `sys_chkTime 123456`

* **Parameter 1:** Timer ID.
* **Return Value:** * **If Timer exists:** Jumps to `id_next`.
  * **If Timer does NOT exist:** Jumps to `id_nextFail`.

---

# 4. Get System Time
*Requires a USER object (Version 013 and above).*
*Example:* `sys_getDate 1`

* **Parameter 1 (Optional):** Time Format (Default is `2`).
  * `0`: `20220213` (YYYYMMDD)
  * `1`: `20220213145924` (YYYYMMDDHHMMSS)
  * `2`: `2022-02-13 14:59:24` (Standard)
  * `3`: `168828968000` (13-digit Timestamp)
  * `4`: Server Uptime (milliseconds).
* **Return Value:** Result stored in `%iter_var_str9`.

---

---

# 7. Create Timer
*Requires a USER object. Each character can have a maximum of 10 active timers.*
*Example:* `sys_onTime 100000101 500 50 123456`

* **Parameter 1:** Script ID to execute periodically.
* **Parameter 2:** Interval in milliseconds (1000ms = 1s).
* **Parameter 3:** Execution count.
* **Parameter 4:** Custom Timer ID.
* **Return Variables:**
  * `%iter_var_str9` = Remaining executions.
  * `%iter_var_str8` = Triggering Timer ID.

---

# 8. Dynamic Script Execution
*Version 014 and above. Asynchronous execution.*
*Example:* `sys_runAction 1000003317 0 0 126 0 Hello!`

* **Parameter 1:** Character ID (`0` for none, `-1` for self).
* **Parameter 2:** Raw Script Code (`next nextfail type data param`).
* **Note:** This runs in a separate thread. Useful for loading external scripts (e.g., from INI files).

---

# 9. Get Skill Name
*Requires a USER object (Version 017 and above).*
*Example:* `sys_getMagicName 1012`

* **Parameter 1:** Skill/Magic ID.
* **Return Value:** Result stored in `%iter_var_str9`. Returns "None" if not found.

---

# 10. Create Magic Effect
*Requires a USER object (Version 017.005 and above).*
*Example:* `sys_magicEffect 100003001 1012 1 100003002 100 8`

* **Parameter 1:** Source Player ID.
* **Parameter 2:** Magic ID.
* **Parameter 3:** Skill Level.
* **Parameter 4:** Target ID.
* **Parameter 5:** Damage Display (Visual only, no actual HP reduction).
* **Parameter 6:** Direction (0-7).

---

# 11. Get Time Interval (Diff)
*Requires a USER object (Version 017 and above).*
*Example:* `sys_getDateDiff 5 2023-07-02 17:21:20 2023-07-08 17:21:20`

* **Parameter 1:** Interval type (0:Year, 1:Month, 2:Day, 3:Hour, 4:Min, 5:Sec, 6:ms).
* **Parameter 2/3:** Start and End time (Date string or Timestamp).
* **Return Value:** Result stored in `%iter_var_str9`. Returns `-1` on error.

---

# 12. Get Random Map Coordinates
*Version 018.030 and above. No Character Object required.*
*Example:* `sys_getRndPos 1000`

* **Parameter 1:** Map ID.
* **Return Keys:**
  * `key_return_getRndPos_x` = Randomized X coordinate.
  * `key_return_getRndPos_y` = Randomized Y coordinate.
* **Note:** Values are returned via **Keys**, not standard variables.
