*Example:* `sys_findStr %iter_var_str9 Eudemon`

* **Parameter 1:** The text to be searched in (Source String).
* **Parameter 2:** The text you want to find (Target String).
* **Return Value:** * **Successful execution:** Jumps to `id_next`

# Replace Text

*Requires a USER object.*
*Example:* `sys_replaceText apple666 apple redApple`

* **Parameter 1:** Original text content.
* **Parameter 2:** The text to be replaced (Target string).
* **Parameter 3:** The replacement text.
* **Return Value:** * **Successful execution:** Jumps to `id_next`
  * **Unsuccessful execution:** Jumps to `id_nextFail`

---
**Note:** After executing `sys_replaceText apple666 apple redApple`, the `%iter_var_str9` variable will return: `redApple666`

**Explanation:**
In `{apple666}`, the word `{apple}` is replaced with `{redApple}`.

# Text Padding (Equilateral Formatting)

*Requires a USER object.*
*Example:* `sys_aequilate 123 4 0`

* **Parameter 1:** The text content to be formatted.
* **Parameter 2:** The final desired length of the string.
* **Parameter 3:** The character used for padding (If set to `-1`, it uses a space). Must be a single character/symbol.
* **Return Value:** * **Successful execution:** Jumps to `id_next`
  * **Unsuccessful execution:** Jumps to `id_nextFail`

---

**Note:** After executing `sys_aequilate 12 4 0`, the `%iter_var_str9` variable will return: `0012`

**Explanation:**
The string `12` is formatted to a total length of `4` characters. Since it only has 2 characters, the remaining 2 empty slots are filled with `0`.

## Example

| id | id_next | id_nextfail | type | data | param |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 100000100 | 100000101 | 0 | 2003 | 0 | `sys_aequilate 123 4 -1` |
| 100000101 | 0 | 0 | 126 | 0 | `%iter_var_str9` |

# Get Formatted Subtext

*Requires a USER object.*
*Example:* `sys_getSubStr 100|2|3 1`

* **Parameter 1:** The full text content (containing delimiters like `|`).
* **Parameter 2:** The position of the subtext to retrieve (Index starts from 1).
* **Return Value:** * **Successful execution:** Jumps to `id_next`.
  * **Unsuccessful execution:** Jumps to `id_nextFail`.
  * The result is stored in `%iter_var_str9`.

---

**Note:** Executing `sys_getSubStr 100|2|3 1` will return `100`. It extracts the 1st subtext from the string "100|2|3".

**Explanation:**
The system treats the `|` symbol as a separator. 
- Position 1: `100`
- Position 2: `2`
- Position 3: `3`

## Example

| id | id_next | id_nextfail | type | data | param |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 100000100 | 100000101 | 0 | 2003 | 0 | `sys_getSubStr 100\|2\|3 1` |
| 100000101 | 0 | 0 | 126 | 0 | `%iter_var_str9` |

# Get Absolute Value

*Requires a USER object.*
*Example:* `sys_abs -1`

* **Parameter 1:** The variable or numeric value you want to get the absolute value of.
* **Return Value:** * **Successful execution:** Jumps to `id_next`.
  * **Unsuccessful execution:** Jumps to `id_nextFail`.
  * **Result:** `%iter_var_str9` = The calculated absolute value.

---

**Explanation:**
The absolute value of a number is its distance from zero, regardless of direction.

# Get Remainder (Modulo)

*Requires a USER object.*
*Example:* `sys_mod 9 2`

* **Parameter 1:** Dividend (The number to be divided).
* **Parameter 2:** Divisor (The number to divide by).
* **Return Value:** * **Successful execution:** Jumps to `id_next`.
  * **Unsuccessful execution:** Jumps to `id_nextFail`.
  * **Result:** `%iter_var_str9` = The remainder of the division.

---

**Explanation:**
The modulo operation finds the remainder after division of one number by another.
- `sys_mod 9 2` returns `1` (Because 9 divided by 2 is 4 with a remainder of **1**).
- `sys_mod 10 2` returns `0` (Because 10 is perfectly divisible by 2).

# Calculate Distance

*Requires a USER object.*
*Example:* `sys_distance 100 100 200 200`

* **Parameter 1:** Coordinate X1
* **Parameter 2:** Coordinate Y1
* **Parameter 3:** Coordinate X2
* **Parameter 4:** Coordinate Y2
* **Return Value:** * **Successful execution:** Jumps to `id_next`.
  * **Unsuccessful execution:** Jumps to `id_nextFail`.
  * **Result:** `%iter_var_str9` = The distance between the two points.

---

**Explanation:**
This function calculates the straight-line distance between two points (x1, y1) and (x2, y2). In programming, this typically uses the Pythagorean theorem formula:
$$\text{distance} = \sqrt{(x2-x1)^2 + (y2-y1)^2}$$

| 100000101 | 0 | 0 | 126 | 0 | `%iter_var_str9` |
