# Auto Compose Eudemon

*Requires a USER object.*
*Example:* `sys_upEudemonMain EudemonName 500001 830000 3`

* **Parameter 1:** Main Eudemon Name or ID. 
    * *Note (v008+):* You can use the Eudemon ID (recommended). 
    * *Note:* Any Eudemon with "奇异兽" (X-Beast/Strange Beast) in its name will be treated as fodder (sub-eudemon).
* **Parameter 2:** Ordinary EXP Ball ID. (Must be full for fully automatic mode).
* **Parameter 3:** Special EXP Ball ID. (Must be full for fully automatic mode).
* **Parameter 4:** Number of compositions. If less than 1, it will compose until resources run out.
* **Return Value:** Always succeeds.

## Example
| id | id_next | id_nextfail | type | data | param |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 100000100 | 0 | 0 | 2003 | 0 | `sys_upEudemonMain Ruyi_Dudu 500001 830000 3` |

# Get Eudemon Info

*Requires a USER object.*
*Example:* `sys_getEudemon 0`

* **Parameter 1:** Position or ID.
    * `0 to 11`: The position in the Eudemon list.
    * `-1` (v018.010+): The Eudemon currently pointed at by the mouse (when triggered by an item).
    * `> 12` (v018.022+): The specific Eudemon ID.
* **Return Value:**
    * **Successful:** Executes `id_next`. Data is stored in:
        * `%iter_var_str9` = Eudemon Name.
        * `%iter_var_str8` = Eudemon Level.
        * `%iter_var_str3` = Eudemon ID.
    * **Unsuccessful:** Executes `id_nextFail`.

# Update Eudemon Visual Data (Client Sync)

**Command:** `sys_upDataEudemonAttr`

### Description
This command updates specific numerical values displayed on the game client. It **only** affects visual display and does not modify the actual backend database stats. You must first use a command to set the actual Eudemon attributes (saving them to the database) before calling this to refresh the user interface.

This automates the refresh process, replacing the old manual method where players had to move pets to the warehouse and back to see updated stats.

### Parameters
* **Parameter 1:** Eudemon Target
    * **Position (0-11):** Targets a Eudemon by its slot position in the inventory.
    * **-1 (v018.010+):** Targets the Eudemon currently pointed at by the mouse when triggered by an item.
    * **Eudemon ID (v018.022+):** If the input value is greater than 12, it is treated as a unique Eudemon ID (obtained via `sys_getEudemon`).
* **Parameter 2:** Attribute Type ID.
* **Parameter 3:** Visual Numerical Value to be displayed.

### Return Value
* **Success:** Executes `id_next`.
* **Failure:** Executes `id_nextFail` (e.g., if the specified position is empty).

### Technical Implementation Note
Stats like HP and Defense are calculated dynamically based on growth rates. To ensure a professional user experience (similar to official compounding), you should calculate the specific value manually before sending it to the client.

**Calculation Formula:**
$$Actual Value = (Growth Rate \times (Level - 1)) + Initial Attribute$$

> [!WARNING]
> The command `sys_addEudemonAttr` has been deprecated and should no longer be used. Setting Eudemon attributes and updating their visual values must now be performed as two distinct steps.
