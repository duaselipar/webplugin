# Write INI File

*Example:* `sys_setini d:\config.ini node key value append_mode`

* **Parameter 1:** File path.
  * `\xxxx.ini` (Starts with `\`): Reads from the same directory as MSG.
  * `c:\xxxx.ini`: Absolute path.
* **Parameter 2:** Section/Node name.
* **Parameter 3:** Key name.
* **Parameter 4:** Key value.
* **Parameter 5 (Optional):** Append mode. 
  * `1` = Append value.
  * `0` = Overwrite value (Default).

| :--- | :--- | :--- | :--- | :--- | :--- |
| 100000100 | 0 | 0 | 2003 | 0 | `sys_setini d:\cfg.ini %user_name Level 125 0` |

# Read INI File

*Requires a USER object.*
*Example:* `sys_getini d:\cfg.ini node key`

* **Parameter 1:** File path (Same path rules as Write INI).
* **Parameter 2:** Section/Node name.
* **Parameter 3:** Key name.
* **Return Value:**
  * **Successful:** Jumps to `id_next`. Result stored in `%iter_var_str9`.
  * **Unsuccessful:** Jumps to `id_nextFail`.

## Example

| id | id_next | id_nextfail | type | data | param |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 100000100 | 100000101 | 100000102 | 2003 | 0 | `sys_getini d:\cfg.ini %user_name Level` |
| 100000101 | 0 | 0 | 126 | 0 | `Value read: %iter_var_str9` |
| 100000102 | 0 | 0 | 126 | 0 | `Read failed!` |

# Read Database Data

*Requires a USER object. Supports long condition expressions from version 016 onwards.*
*Example:* `sys_getBaseData cq_user account_id id=%user_id`

* **Parameter 1:** Table name.
* **Parameter 2:** Field name to read.
* **Parameter 3:** Condition expression (e.g., `` `id`=%user_id ``).
* **Return Value:**
  * **Successful:** Jumps to `id_next`. Result stored in `%iter_var_str9`.
  * **Unsuccessful:** Jumps to `id_nextFail`.

## Example

| id | id_next | id_nextfail | type | data | param |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 100000100 | 100000101 | 100000102 | 2003 | 0 | `sys_getBaseData cq_user account_id id=%user_id` |
| 100000101 | 0 | 0 | 126 | 0 | `Value read: %iter_var_str9` |
| 100000102 | 0 | 0 | 126 | 0 | `Read failed!` |

# Write Database Data

*Supports long condition expressions from version 016 onwards.*
*Example:* `sys_setBaseData table field new_value condition`

* **Parameter 1:** Table name.
* **Parameter 2:** Field name to update.
* **Parameter 3:** New value for the field.
* **Parameter 4:** Condition expression (e.g., `` `name`=Jasmine ``).
* **Return Value:**
  * **Successful:** Jumps to `id_next`.
  * **Unsuccessful:** Jumps to `id_nextFail`.

## Example

| id | id_next | id_nextfail | type | data | param |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 100000100 | 100000101 | 100000102 | 2003 | 0 | `sys_getBaseData cq_user account_id id=%user_id` |
| 100000101 | 100000104 | 100000103 | 2003 | 0 | `sys_setBaseData account superpass '123456' id=%iter_var_str9` |
| 100000102 | 0 | 0 | 126 | 0 | `Failed to read account ID` |
| 100000103 | 0 | 0 | 126 | 0 | `Failed to set super password` |
| 100000104 | 0 | 0 | 126 | 0 | `Super password set successfully` |
