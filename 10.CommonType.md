# NPC Creation (2007) Detailed Explanation

This reference table details the parameters used in the `2007` script command for dynamic NPC creation.

### NPC Creation Parameters

| Parameter | Function | Remarks |
| :--- | :--- | :--- |
| **name** | NPC Name | Only Guild Marks, Item Racks, and Statue NPCs can display custom names. |
| **type** | NPC Type | Refers to the NPC Type list; defines the type, not the behavior. |
| **sort** | NPC Behavior | Usually set to `0`. Behavior determines how the **linkid** is interpreted. |
| **lookface** | Appearance ID | If the NPC type is a **Statue**, this represents the direction ($0-7$). |
| **ownertype** | Owner Type | `0`: Default, `1`: Player, `2`: System, `3`: NPC. |
| **ownerid** | Owner ID | Set based on `ownertype` (e.g., if type is `1`, set this to the Player's ID). |
| **mapid** | Map ID | The ID of the map where the NPC will be created. |
| **posx** | Map X | X-coordinate on the map. |
| **posy** | Map Y | Y-coordinate on the map. |
| **life** | HP | The health points of the NPC. |
| **base** | Base ID | Creates an NPC using another NPC's data as a template. Set to `0` if unsure. |
| **linkid** | Link ID | Varies by `sort`; can be a Map ID or a Script ID. |
| **task0** | Script ID | For special NPCs (type 20), can be a list (e.g., Chests). For hair style: $Style \times 10000$ (e.g., 1280000). |
| **task1** | Script ID | Special NPCs: Armor/Equipment ID. |
| **task2** | Script ID | Special NPCs: Right-hand weapon ID. |
| **task3** | Script ID | Special NPCs: Left-hand weapon ID. |
| **task4** | Script ID | Frame/Framework ID. For Statue NPCs, refer to the note below. Must be set with `task5`. |
| **task5** | Script ID | Posture ID. Use `0100` if unsure. |
| **task6** | Script ID | Model/Appearance ID (e.g., Human, Monster, Ghost). Remove equipment settings if not using a human model to avoid display errors. |

| **data0-3** | NPC Variables | Internal numerical variables for the NPC. |
| **datastr** | NPC String Var | Text-based variable for the NPC. |

### Task4 Structure Analysis (Statue NPCs)

When the NPC is a **Statue**, `task4` uses a bit-field structure to define its visual state:

* **Bits 1-7:** Frame Position. Defines which animation frame is frozen for the dynamic model.
* **Bit 8:** Airborne Status. Determines if the statue is floating.
* **Bits 9-12:** Halo Type. Represents the type of halo effect ($1-5$).

**Decimal Calculation Method:**
$$TotalValue = Frame + AirborneValue + HaloValue$$

* **Airborne Status:** Floating = `128`, Grounded = `0`.
* **Halo Level Values:**
    * Level 2 = `256`
    * Level 3 = `512`
    * Level 4 = `1024`
    * Level 5 = `2048`

# Monster AI Behavior Reference Table

| Value | AI Behavior | Remarks |
| :--- | :--- | :--- |
| **1** | Priority: Attack targets that are attacking the owner. | |
| **2** | Priority: Attack targets that are attacking itself. | |
| **3** | Priority: Attack targets with negative PK/Alignment values. | |
| **4** | Switch targets after every three attacks. | |
| **5** | Priority: Attack enemies that are attacking the owner's Eudemons (pets from other players). | |
| **6** | Actively attack monsters in field of view (FOV). Priority is given to rushing into the densest group of enemies in FOV. | |
| **7** | Attack monsters in FOV. Priority: 1. Enemies attacking self, 2. Enemies attacking the owner. | |
| **8** | Attack any enemy in FOV. No fixed target; randomly selects a new enemy for each attack. | |
| **9** | Kite Behavior: If a target gets within 5 cells, flee 5 cells away before attacking (always maintains a 5-cell distance). | |
| **10** | Random Movement: Moves 3 cells in one of 8 random directions after each attack, but stays within 10 cells of the owner. | |
| **11** | Guardian: Always stays within 3 cells of the owner. If the specific cell is blocked, stays in the nearest available outer cell. | |
| **12** | Patrol: While owner moves, if an enemy is between 5 and 8 cells away, patrol within 4 cells of the owner in the enemy's direction every 3 seconds. Disabled if enemy enters within 5 cells. | |
| **13** | Follow: Stays within 6 cells of the owner during long-distance movement. If the owner moves further, it will follow to catch up. | |
| **14** | Rest: Sits and rests within 8 cells of the owner when there are no active attack targets. | |
| **15** | Evasive Counter: When attacked, 70% chance to move 5 cells away, 30% chance to attack. | |
