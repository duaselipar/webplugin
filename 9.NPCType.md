# Delete NPC at Specific Location

**Command:** `sys_delNpc`

* **Requirement:** The character must be on the current map.
* **Restriction:** Can only delete dynamic NPCs (those created via script 2007).
* **Description:** Provides a precise method for deleting NPCs at specific coordinates, solving the problem of deleting non-interactive NPCs of the same type.
* **Parameters:**
    1. **Map ID**
    2. **Map X**
    3. **Map Y**
* **Return Value:** Always succeeds.

### Example
| id | id_next | id_nextfail | type | data | param |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 100000100 | 0 | 0 | 2003 | 0 | `sys_delNpc 1000 100 100` |

# Delete NPC (Enhanced Version)

**Command:** `sys_delNpcEx`

* **Restriction:** Can only delete dynamic NPCs (created via script 2007).
* **Description:** Deletes NPCs based on condition expressions. It is strongly recommended to use multiple conditions to avoid accidental mass deletion (e.g., deleting all NPCs on a map).
* **Parameters:**
    1. **Condition Expression:** Multiple conditions can be combined using spaces. Only the `=` operator is supported.
* **Supported Condition Keys:**
    * `name` (NPC Name)
    * `type` (NPC Type)
    * `id` (NPC ID)
    * `mapid` (Map ID)
    * `posx` (X Coordinate)
    * `posy` (Y Coordinate)
    * `findname` (Checks if NPC name contains specific characters)
    * `ownerid` (NPC Owner ID)
* **Return Value:** Always succeeds.

### Example
| id | id_next | id_nextfail | type | data | param |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 100000100 | 0 | 0 | 2003 | 0 | `sys_delNpcEx name=Haha type=2` |

# Get NPC Count

**Command:** `sys_getNpcNum`

* **Requirement:** Requires a User object.
* **Restriction:** Only counts dynamic NPCs (created via script 2007).
* **Description:** Retrieves the count of NPCs matching the condition expression.
* **Parameters:**
    1. **Condition Expression:** (Same conditions supported as `sys_delNpcEx`).
* **Return Value:** Always succeeds.
* **Output:** The count is stored in the variable `%iter_var_str9`.

### Example
| id | id_next | id_nextfail | type | data | param |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 100000100 | 100000101 | 0 | 2003 | 0 | `sys_getNpcNum mapid=1000` |
| 100000101 | 0 | 0 | 126 | 0 | `%iter_var_str9` |

# Create Character Statue

**Command:** `sys_createStatue`

* **Requirement:** Requires a User object.
* **Description:** Creates a character statue that can be targeted and attacked.
* **Parameters:**
    1. **Character ID:** The ID of the player the statue represents. If representing someone else, that player must be online.
    2. **Statue Name:** Max 8 characters.
    3. **Map ID**
    4. **Map X**
    5. **Map Y**
    6. **Flying Status:** 0 or 1.
    7. **Halo:** 1 to 4 (Use 0 for none).
    8. **Special Effects:** 1 to 4 (Use 0 for none).
    9. **Direction:** 0 to 7 (Standard is 7).
    10. **HP:** Amount of health for the statue.
    11. **Soul Mode:** 1 for ghost/spirit model, 0 for standard character model.
* **Return Value:** * **Success:** Jumps to `id_next`.
    * **Failure:** Jumps to `id_nextFail`.

### Example
| id | id_next | id_nextfail | type | data | param |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 100000100 | 100000101 | 0 | 2003 | 0 | `sys_createStatue %user_id Haha %user_map_id %user_map_x %user_map_y 1 4 1 7 1000 0` |
