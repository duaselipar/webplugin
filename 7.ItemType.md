# Drop All Items

*Requires a USER object.*
*Example:* `sys_dropAll`

* **Effect:** Drops every item in the player's inventory onto the ground.
* **Return Value:** Always succeeds. (Stops automatically if inventory is empty).

## Example

| id | id_next | id_nextfail | type | data | param |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 100000100 | 0 | 0 | 2003 | 0 | `sys_dropAll` |

# Pick Up Items

*Requires a USER object.*
*Example:* `sys_pickItem 851526 851526`

* **Parameter 1-10 (Optional):** Item IDs to pick up. You can specify up to 10 specific IDs.
* **Note:** If no parameters are provided, the player will attempt to pick up all nearby items.
* **Return Value:** Always succeeds.

---

# Random Item Drop

*Requires a USER object (Version 011 and above).*
*Example:* `sys_dropItemRnd 5`

* **Parameter 1 (Optional):** Number of items to drop. Defaults to `1` if empty.
* **Return Value:** Always succeeds.

---

# Drop Specified Item

*Requires a USER object (Version 011 and above).*
*Example:* `sys_dropItem 1037150`

* **Parameter 1:** The Resource ID of the item to drop.
* **Note:** If the player has multiple items of the same ID, only one is dropped. If the item is a stack, the entire stack might be dropped.
* **Return Value:** Always succeeds.

---

# Drop Equipped Item

*Requires a USER object (Version 011 and above).*
*Example:* `sys_dropEquip 1` (Drops helmet).

* **Parameter 1:** Equipment Position ID (Refer to Equipment Reference Table).
* **Note:** Ensure the slot contains an item and there is at least **one empty inventory slot**, as the system un-equips the item before dropping it.
* **Return Value:** Always succeeds.

# Award Specified Item

*Requires a USER object (Version 015 and above).*
*Example:* `sys_awardItem 1000000`

* **Parameters:**
    1. **Item ID** (Required)
    2. Durability (Optional)
    3. Max Durability (Optional)
    4. Identified Status (Optional)
    5. Socket 1 | 6. Socket 2 | 7. Magic Soul | 8. Battle Soul Level
    9. Earth Atk | 10. Water Atk | 11. Fire Atk | 12. Wind Atk
    13. Bound Status | 14. Suspicious Status
    15. **Data** (Energy value for EXP Balls: 1% = 10000)
* **Return Value:** Success jumps to `id_next`, Failure jumps to `id_nextFail`.
* **Description:** Unlike standard award commands, this allows dynamic awarding via variables/INI files because all parameters are in the `param` field.

# Delete or Arrange Stacked Items

*Requires a USER object (Version 015 and above).*
*Example:* `sys_delItemPile 1000000 10 100`

* **Parameter 1:** Item ID (Must be a stackable item).
* **Parameter 2:** Quantity to delete.
* **Parameter 3:** Stack Limit (Must match the database value).
* **Return Value:**
    * **Successful:** Executes `id_next`. `%iter_var_str9` = Amount deleted.
    * **Unsuccessful:** Executes `id_nextFail`. `%iter_var_str9` = Total sum of that item in inventory.
* **Feature:** If deletion fails (not enough items), the system automatically "arranges" the fragments into full stacks.

---

# Arrange Stacked Items (Cleanup)

*Requires a USER object (Version 015 and above).*
*Example:* `sys_arrangeItemPile 1000000 100`

* **Parameter 1:** Item ID.
* **Parameter 2:** Stack Limit.
* **Return Value:** Always succeeds. `%iter_var_str9` = Total count of the item.
* **Note:** This merges fragmented stacks into clean, full stacks. "Gift" (Bound) items will be converted to normal items if mixed.

---

# Award Stacked Items

*Requires a USER object (Version 015 and above).*
*Example:* `sys_awardItemPile 1000000 500 100`

* **Parameter 1:** Item ID.
* **Parameter 2:** Total Quantity to give.
* **Parameter 3:** Stack Limit.
* **Return Value:** Always succeeds.
* **Note:** Automatically groups items into stacks based on the limit. Does not check for inventory space; script must check manually.

# Award Custom Star Eudemon (Baby)

*Requires a USER object (Version 016/017 and above).*
*Example:* `sys_awardBaby 1071980 10000 0 0 0 0 ...`

* **Parameters (All 21 are Required in v017):**
    1. Item Type ID | 2. Level | 3. HP Growth (x100) | 4-5. Max/Min P-Atk Growth (x1000)
    6. P-Def Growth (x1000) | 7-8. Max/Min M-Atk Growth (x1000) | 9. M-Def Growth (x1000)
    10. Initial HP | 11-12. Initial Max/Min Atk | 13. Initial P-Def | 14-15. Initial Max/Min M-Atk
    16. Initial M-Def | 17. Element | 18. Luck | 19. Rebirth Count | 20. Intimacy
    21. Archaic Score (Used to adjust Star Rating).
* **Note:** This allows creating specific high-star "fodder" or secondary Eudemons beyond standard XO/O types.

# Get Item Count in Inventory

*Requires a USER object (Version 017 and above).*
*Example:* `sys_getItemNum 1037160`

* **Parameter 1:** Item ID.
* **Note:** This counts the number of **individual item entries** (Best for non-stackable items). For total counts of stackable items, use the `sys_arrangeItemPile` return value.
* **Return Value:** `%iter_var_str9` = Total quantity found.
