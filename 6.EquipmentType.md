# Equipment Position Reference Table
*Use these IDs for all equipment-related commands.*

| ID | Position |
| :--- | :--- |
| 1 | Head (Helmet) |
| 2 | Necklace |
| 3 | Armor |
| 4 | Weapon (Right Hand) |
| 5 | Weapon (Left Hand) |
| 6 | Right Bracer |
| 7 | Left Bracer |
| 8 | Shoes |
| 9 | Mount |
| 10 | Sprite / Eudemon Slot |
| 11 | Cloak |
| 12 | Fashion / Empty EXP Ball |

# Unequip Equipment

*Requires a USER object.*
*Example:* `sys_unEquip 1` (Unequips helmet).

* **Parameter 1:** Equipment Position ID (Refer to the reference table).
* **Return Value:** Always succeeds.

## Example

| id | id_next | id_nextfail | type | data | param |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 100000100 | 0 | 0 | 2003 | 0 | `sys_unEquip 1` |

---

# Equip Equipment

*Requires a USER object.*
*Example:* `sys_inEquip 1 45135260`

* **Parameter 1:** Equipment Position ID.
* **Parameter 2:** Item Type ID (The ID from the items database).
* **Note:** Ensure the item is valid for the specified slot, otherwise it will fail.
* **Return Value:** Always succeeds.

## Example

| id | id_next | id_nextfail | type | data | param |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 100000100 | 0 | 0 | 2003 | 0 | `sys_inEquip 1 45135260` |

# Upgrade Equipment Quality

*Requires a USER object. Used to upgrade item quality (e.g., to Unique/Elite).*
*Example:* `sys_UpEpQuality 3 1037160 10`

* **Parameter 1:** Equipment Position ID. (Fails if slot is empty).
* **Parameter 2:** Upgrade Item ID (Usually Soul Crystal ID).
* **Parameter 3:** Number of attempts. Stops automatically if crystals run out.
* **Return Value:** Always succeeds.

## Example

| id | id_next | id_nextfail | type | data | param |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 100000100 | 0 | 0 | 2003 | 0 | `sys_UpEpQuality 3 1037160 10` |

# Check Equipment Name by Position

*Requires a USER object.*
*Example:* `sys_chkEquipByPos 1`

* **Parameter 1:** Equipment Position ID.
* **Return Value:**
    * **Successful (Item equipped):** Executes `id_next`. The item name is stored in `%iter_var_str9`.
    * **Unsuccessful (Slot empty):** Executes `id_nextFail`.

## Example

| id | id_next | id_nextfail | type | data | param |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 100000100 | 100000101 | 0 | 2003 | 0 | `sys_chkEquipByPos 1` |
| 100000101 | 0 | 0 | 126 | 0 | `You are wearing: %iter_var_str9` |

# Delete Specified Equipment

*Requires a USER object (Version 014 and above).*
*Example:* `sys_delEquip 3` (Deletes armor).

* **Parameter 1:** Equipment Position ID.
* **Return Value:** Always succeeds.
* **Important Note:** This method does not check if the position actually contains an item. Please ensure the player has at least one empty inventory slot when deleting.

## Example

| id | id_next | id_nextfail | type | data | param |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 100000100 | 0 | 0 | 2003 | 0 | `sys_delEquip 3` |

# Get Equipment or Item Attribute

*Requires a USER object.*
*Example:* `sys_getEqAttr 0 1`

* **Parameter 1:** Equipment Position. (Fails if the slot is empty). 
    * *Special Note:* If the value is **greater than 12**, the system treats it as an **[Item Resource ID]** to retrieve attributes for a specific item ID.
* **Parameter 2:** Attribute Type ID (Refer to the Attribute Table below).
* **Return Value:**
    * **Successful:** Executes `id_next`. The attribute value is stored in `%iter_var_str9`.
    * **Unsuccessful:** Executes `id_nextFail`.

## Example

| id | id_next | id_nextfail | type | data | param |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 100000100 | 100000101 | 0 | 2003 | 0 | `sys_getEqAttr 1 104` |
| 100000101 | 0 | 0 | 126 | 0 | `Equipment Level: %iter_var_str9` |

# Add Equipment or Item Attribute

*Requires a USER object.*
*Example:* `sys_addEqAttr 0 17 2`

* **Parameter 1:** Equipment Position. (Fails if the slot is empty).

* **Parameter 3:** Value to add.
* **Return Value:**
    * **Successful:** Executes `id_next`.

| :--- | :--- | :--- | :--- | :--- | :--- |
| 100000100 | 0 | 0 | 2003 | 0 | `sys_addEqAttr 0 17 2` |
